# JARAMA Global Website

This project is the front-end website for JARAMA Global Trade. It is built with React and Vite and does not include the former backend API.

## Requirements

- Node.js 18+
- npm

## Run locally

```powershell
npm install
npm run dev
```

## Build for production

```powershell
npm run build
```

## Lint

```powershell
npm run lint
```

This frontend is intentionally standalone. If you later add a backend enquiry service, set its endpoint in the site configuration and update the form handling.
